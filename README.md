# Nav2 Regression Testing Suite

Automated navigation metrics collection, validation, and CI/CD integration for ROS 2 Jazzy and Nav2.

## Components
- **metrics_collector.py**: Captures navigation performance metrics during Gazebo simulation.
- **regression_checker.py**: Validates metrics against defined thresholds (`test_thresholds.json`).
- **GitHub Actions**: Automated CI pipeline (`ros2_ci.yml`).
